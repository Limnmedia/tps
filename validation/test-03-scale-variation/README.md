# Test 3 — Scale Variation

**Status: Not Yet Performed**

## Purpose

Repeat view transfer with one declared change in physical scale or capture geometry.

## Procedure

1. Establish and record the original camera view and TPS reference on Setup 1.
2. Capture `original.png`.
3. Establish Setup 2 and declare exactly what changed.
4. Record original-reference and second-setup measurements separately.
5. Use registered visual comparison and TPS to recover the view on Setup 2.
6. Capture `recovered.png`.
7. Create `comparison.png` showing the registered original and recovered images.
8. Complete `measurements.md` with the scale/gate condition and observations.

## Scale distinction

Choose and document one declared condition:

- **Physical scale change:** physical distances or scene geometry change.
- **Image-gate change:** active image gate, crop, resampling, image dimensions, or capture framing changes.

These conditions are not assumed to be mathematically equivalent.

## Evidence

The original/recovered registered image comparison is primary. Measurements and operator observations are supporting evidence.
