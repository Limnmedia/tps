# Test 2 — View Transfer

**Status: Not Yet Performed**

## Purpose

Record a TPS reference on one physical setup and use it to reproduce the recorded view on a second physical setup.

## Procedure

1. Establish and record the original camera view and TPS reference on Setup 1.
2. Capture `original.png`.
3. Establish Setup 2 and identify the corresponding A, B, and C points.
4. Measure and record Setup 2’s actual relationships; preserve the original reference unchanged.
5. Use the original image correspondences in registered comparison to recover the view on Setup 2.
6. Capture `recovered.png`.
7. Create `comparison.png` showing the registered original and recovered images.
8. Complete `measurements.md` with separate original-reference and second-setup measurements and observations.

## Evidence

The original/recovered registered image comparison is primary. Measurements and operator observations are supporting evidence. Do not assume that changed geometry is equivalent to the original.
